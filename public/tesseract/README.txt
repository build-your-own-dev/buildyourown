Menuva bundles browser OCR assets locally so menu images never need to leave the
user's device.

- Tesseract.js worker: https://github.com/naptha/tesseract.js (Apache-2.0)
- Tesseract.js Core: https://github.com/naptha/tesseract.js-core (Apache-2.0)
- German trained data: https://github.com/naptha/tessdata (MIT package metadata)

The dependency versions used by this project are recorded in package-lock.json.
