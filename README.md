# BuildYourOwn – GitHub Pages

Der Inhalt dieses Ordners kann direkt in den Root deines GitHub-Pages-Repositories hochgeladen werden.

1. Alle Dateien inklusive `index.html`, `assets`, `.nojekyll` und `CNAME` in den Repository-Root legen.
2. Unter **Settings → Pages** als Quelle den gewünschten Branch und den Ordner `/ (root)` auswählen.
3. Die enthaltene `CNAME`-Datei verwendet `build-your-own.ch` als Custom Domain.

Alle internen Links und Assets verwenden relative Pfade und funktionieren deshalb sowohl auf einer Custom Domain als auch unter einem GitHub-Repository-Pfad.
